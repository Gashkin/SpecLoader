# Start or resume a refinement session

Use this entry point at a specific Git commit. Open [refinement lead](refinement-lead.md) at the same revision. The [independent challenger](independent-challenger.md) can run separately when the host supports delegation. Use the project’s current policy for authority and source ownership. SpecLoader’s [repository guidance](../../../README.md) identifies its sources of truth.

## Opening assignment

Open a new top-level Work conversation. Give it the following short assignment with the fields filled in. Supply pointers to live sources and leave the investigation to the session.

> Use the refinement lead brief at [entry-point URL pinned to commit]. Investigate [one question] for [story and canonical source]. The required outcome is [decision or finding needed]. Preserve [settled constraints]. You may [allowed reads, writes and delegation]. [Owner] retains [reserved decisions]. Delegate a bounded read-only challenge where supported. Save the result to [authorised destination] and leave a resume handoff.

Record the opening assignment, revision, session reference or inspectable redacted evidence, and any inherited project context. Open both role links from the pinned revision. If the host cannot read the package or start a separate challenger, record the limitation. Label a serial challenge accurately.

## Handoff and verification

Record the outcome in the canonical task or discovery record. A resume handoff needs only the finding and its approval state, the package revision, links to the current evidence, changed assumptions, the outstanding decision and owner, and the next useful action. To resume, give a fresh reader that handoff and ask them to recover the recommendation, approval state and next action from its sources. Record what they recovered and correct material discrepancies.

For a demonstration, retain the challenger’s actual assignment, returned evidence and the lead’s disposition. Check material claims against their sources. Record routine and necessary interruptions, repeated reads and their causes, and preparation or maintenance effort. Label counts and estimates as proxies. Record actual usage only when exposed. Keep private evidence in its authorised home.
