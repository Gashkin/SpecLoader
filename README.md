# SpecLoader

Evidence-based discovery, assessment and improvement of governed software development practices.

SpecLoader helps software projects understand how they actually work, identify gaps and contradictions, and make evidence-based improvements to their development practices.

It is an independent product and repository. It is not part of Household Budget Manager (HBM); HBM is intended to be its first brownfield pilot and consumer.

Product requirements, priorities, delivery decisions and Story status are maintained in the SpecLoader Notion project. This repository is the source of truth for source code, engineering specifications, architecture, ADRs, tests and engineering guidance.

## Project status

SpecLoader is in its initial foundation stage. Product discovery and refinement are ongoing. This repository currently establishes the independent project home and its initial repository validation.

## Governance

Changes are developed on short-lived branches and proposed through pull requests targeting `main`. Ger retains product ownership and final merge authority.

No credentials, tokens, passwords or environment-specific secrets belong in this repository.
